# Formulario Dinámico para Gestión de Servicios para Pymes

Este proyecto presenta una herramienta desarrollada en **Microsoft Excel**, con soporte en **VBA (Visual Basic for Applications)** y **Power Query**, orientada a la **gestión y registro de servicios** brindados por pequeñas y medianas empresas.  
Fue diseñado para optimizar la **carga, validación y organización de información operativa**, permitiendo una administración más eficiente de solicitudes y atenciones, y facilitando el análisis posterior de datos.

---

## 🎯 Objetivo del proyecto

El formulario permite **registrar y controlar solicitudes de servicios** de manera dinámica, organizada y trazable.  
Su estructura combina formularios interactivos con validaciones automáticas, controles de errores y botones de acción, logrando un flujo de trabajo rápido, confiable y adaptable a distintos rubros de servicios.

El proyecto nace como una **iniciativa personal**, derivada de la detección de necesidades reales en un entorno laboral vinculado a la **medicina laboral**, y fue posteriormente adaptado y depurado para compartirlo como ejemplo funcional libre de información sensible.

---

## ⚙️ Características principales

- **Interfaz dinámica mediante formularios VBA**, diseñada para una carga ágil de datos.  
- **Validaciones de datos y manejo de errores** integrados, que garantizan la consistencia de la información.  
- **Asignación automática de ID** para identificar y diferenciar cada registro.  
- **Carga temporal en tabla de chequeo** antes de su incorporación definitiva en la base de datos, permitiendo revisar y confirmar la información.  
- **Integración con Power Query** para la organización, filtrado y análisis posterior de los datos.  
- **Modularidad del código VBA**: cada módulo cumple una función específica dentro del flujo del formulario.  

---

## 🧠 Tecnologías y herramientas utilizadas

- **Microsoft Excel (Libro con macros habilitadas)**  
- **VBA (Visual Basic for Applications)**  
- **Power Query**  
- **Validaciones de datos y controles de formulario**

---

## 🚀 Uso del formulario

1. Abrir el archivo `Formulario Dinamico.xlsm` habilitando las macros.  
2. Completar los campos del formulario según el servicio a registrar.  
3. Utilizar los controles y botones para validar y confirmar los datos.  
4. La información se trasladará automáticamente a la tabla correspondiente.  

El sistema está preparado para ser adaptado a otros tipos de servicios o rubros de negocio, conservando su estructura de validaciones y registro dinámico.
